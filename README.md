# Python Practice Snippets

A small practice repository for learning Python basics, exception handling, input validation, and file handling.

## What’s inside
- basic Python syntax
- `try`, `except`, `else`, and `finally`
- common built-in exceptions
- input validation
- saving and loading text files safely

## Folder guide
- `basics/` — simple beginner examples
- `exceptions/` — exception handling practice
- `input-validation/` — user input checks
- `file-handling/` — safe file read/write examples

## How to run
Open any `.py` file and run it with:

```bash
python filename.py
```

## What I learned
- how to handle errors without crashing
- how to validate user input
- how to work with files safely
- how to organize a GitHub repo clearly
